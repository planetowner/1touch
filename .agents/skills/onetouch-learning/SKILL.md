# OneTouch Learning

- Start with the overall structure and runtime flow from `docs/project-map.md`; show code examples after the mental model is clear.
- Explain unfamiliar Dart and Flutter concepts in plain language and connect them to concrete files in this repository.
- Format quizzes as Problem -> Answer -> Explanation.
- During an interactive quiz, do not reveal the full answer until every question is answered correctly. Identify the misunderstood concept and give a focused hint.
- Place a requested code-learning playground under `docs/` as a standalone HTML file. Do not modify application code unless the user explicitly asks for it.
- Keep teaching artifacts separate from production source and label simplified examples that omit production concerns.
