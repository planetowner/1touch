# Sportmonks 경기 보충 기록 · 2026-09-21

17/18~26/27 기본 적재 후 발견한 이벤트·명단·선수 통계 차이를 재검증했다. 선수 신원, 당시 경기표, 실제 출전 및 교체 기록으로 확인한 입력만 공통 보정 목록에 추가했다.

## 코드 변경

- 이벤트 한 행에 투입·아웃 선수 프로필이 모두 필요할 수 있어 검증된 프로필 목록을 상세·라이브 저장 경로에서 함께 사용한다.
- 감독 카드가 같은 팀 감독 ID를 선수 칸에 담은 경우 선수 연결을 비우고 카드 자체는 보존한다. 실제 선수 명단에 있는 ID는 이 규칙으로 제거하지 않는다.
- 잘못 연결된 선수, 중복 명단·이벤트, 득점·도움 선수, 출전 시간 및 기존 통계 값을 확인된 이벤트·명단 ID에 한해 정정한다. 없는 명단·이벤트·통계는 새로 만들지 않는다.
- 2017년 Trapani·Carpi 경기에 재창단 구단 ID가 섞인 문제는 두 경기의 관련 컬렉션에서만 정정한다. 전역 구단 병합은 하지 않는다.
- 현재 시즌 선수 통계 보충은 공급자가 종료로 확인한 경기만 대상으로 삼는다. 과거 시즌의 선택 순서와 재개 동작을 유지한다.
- 라이브 수집에서 시작 시각이 지났는데 NS로 남은 현재 시즌 경기도 다시 확인한다. 일정 선택 보충도 기존 참가 팀·국내컵 범위 검증을 공유한다.

## 범위와 확인 방식

추가 상세 감사 후보는 과거 9시즌 8,635경기와 현재 시즌 95경기다. 기본 적재 전체 건수와 추가 보충 후보 건수는 다르다. 과거 시즌은 이벤트를 대조하고, 국내컵 및 명시적으로 확인한 경기만 명단·선수 통계를 함께 대조한다.

변경 전 행과 공급자 원문을 저장하고, 저장 전 전체 범위의 참가 팀·선수 연결·중복 키·빈 응답을 검사한다. 각 경기는 트랜잭션으로 저장한 후 재조회한다. 감독 카드의 `-4분`으로 발생한 실제 저장 실패를 확인한 뒤에는 시간 열의 범위도 전체 쓰기 전에 검사하도록 작업 스크립트를 보완했다. 시간 값은 임의로 0으로 바꾸지 않았다.

별도 체크아웃에서 관련 회귀 테스트 129개가 통과했다. 실제 음수 카드 입력은 DB와 같은 범위 제약을 둔 테스트에서 실패를 재현하고, 5경기 9개 시간 보정 후 카드 유형·선수 NULL 연결·추가 시간을 보존해 저장되는지 확인했다.

명단을 교체하면 FK의 `ON DELETE CASCADE`로 선수 통계도 삭제되므로 보충 스크립트는 값이 같아도 두 컬렉션을 함께 저장한다. 18533253에서 저장 후 검사로 발견한 통계 4행 삭제는 원문과 변경 전 백업을 대조해 복구했다. 실제 미출전 후보 신원 정정 3경기를 사용하는 별도 검사 2개에서 일반 조회와 보존 원문 재개 모두 통계를 유지하는지 확인했다.

운영 DB 보충과 별도 읽기 검증을 완료했다. 최종 확인 시각은 2026-09-21T19:55:56.248950+00:00이다. 과거 9시즌 8,635경기의 대상 컬렉션을 보존 원문에 검증된 보정을 적용한 결과와 다시 대조했으며 차이는 0건이었다. 대조한 저장 행은 이벤트 135,449행, 명단 67,773행, 선수 통계 470,996행이다. 후보에 포함된 모든 경기의 모든 컬렉션을 새로 썼다는 뜻은 아니다.
